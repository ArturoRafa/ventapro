WhatsApp — Documentacion Tecnica

No es una pantalla — es un deep link wa.me/{telefono_cliente} que aparece como boton en POS y Creditos

Implementacion: Solo window.open('https://wa.me/...') — no hay backend, no hay API de WhatsApp Business.
Activacion: Switch usesWhatsapp en Configuracion (on/off).
Campo whatsappNumber: Se eliminara del backend — no se usa. El mensaje va al telefono del cliente, no del negocio.
Condicion: Boton visible solo si usesWhatsapp = true AND el cliente tiene telefono registrado.
toggle_on Requiere: usesWhatsapp = true + cliente con telefono
settings Ir a Configuracion (switch WhatsApp)

Formato de URL
Construccion del deep link
const phone = customer.phone.replace(/\D/g, '');
const message = encodeURIComponent(`
  Hola ${customer.name}, tu compra en
  ${config.businessName}:
  Venta #${sale.id}
  Total: ${formatCurrency(sale.total)}
`);

const url = `https://wa.me/${phone}?text=${message}`;
window.open(url, '_blank');
